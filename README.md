# QBiC Maven Repository — `gh-pages`

This branch is served as a **static Maven repository** at
<https://qbicsoftware.github.io/maven-repository/releases>.

It holds artifacts that QBiC Java projects need but that Maven Central does not carry.
It contains no source code; do not commit anything but Maven layout files here.

- What is hosted, why, and how to consume it: see the [repository README](../README.md)
  on `main`.

Do not edit files in this branch by hand — see "Operations" in the main README.
