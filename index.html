Consume it

<repository>
  <id>qbic-maven-repository</id>
  <name>QBiC Maven Repository</name>
  <url>https://qbicsoftware.github.io/maven-repository/releases</url>
  <releases>
    <checksumPolicy>fail</checksumPolicy>
    <enabled>true</enabled>
  </releases>
  <snapshots>
    <enabled>false</enabled>
  </snapshots>
</repository>

No <updatePolicy>always</updatePolicy>. This repository is static: a coordinate never changes underneath a build. always would turn an unreachable host into a per-build stall.

About

zzzz-openbis-api was previously resolved from the QBiC Nexus instance, which is not reachable from GitHub Actions egress — that broke every cold-cache CI build. Its POM declares no parent, no dependencies and no plugins, so mirroring it is two files and two checksums. The jar and POM are byte-identical to the openBIS originals. The zzzz- prefix is deliberate upstream: openBIS sorts its own modules last. openBIS is licensed under the Apache License 2.0, which permits redistributing the unmodified binary.

Repository documentation: github.com/qbicsoftware/maven-repository

Served from the gh-pages branch. Layout: releases/groupId/artifactId/version/. Nothing publishes here automatically and there is no maven-metadata.xml.
