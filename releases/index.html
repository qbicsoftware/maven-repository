Verifying by hand

A 404 here does not mean resolution is broken. Check a real file path instead:

curl -sI https://qbicsoftware.github.io/maven-repository/releases/life/qbic/zzzz-openbis-api/20.10.7.3/zzzz-openbis-api-20.10.7.3.pom

Resolution failing after an outage? Maven caches failed lookups as *.lastUpdated markers and will not retry them. Clear them, or run with -U:
find ~/.m2/repository -name "*.lastUpdated" -delete
